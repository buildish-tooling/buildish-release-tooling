This release supports generated GitHub Action content in the modern release lifecycle.

- Keep the reviewed source commit as the authority for source checks and release notes while
  candidate and final tags target one bound materialized child containing generated executables.
- Add `bind-materialization` and `import-materialization` commands for digest-bound Git bundle
  transport between credential-separated build and publication jobs. Trusted imports compare
  producer state with the original resolution and enforce configured paths and Git identities.
- Preserve the exact approved materialized commit through promotion and recovery. Publish its
  objects through a retained internal Git ref before creating tags, with destination, conflict
  and race checks. Record truthful materialized-content and source-snapshot promotion evidence.
- Extend lifecycle regression coverage and the local harness with generated-content direct and
  candidate releases, shallow imports, immutable publication, retries, and execution from tagged
  Action content. Isolate inherited release tags only in fresh disposable harness repositories.
- Add developer scripts for an independent `versioned-docs` worktree and incremental or full
  release-documentation imports from Git tags, preserving curated records during incremental imports.
- Harden PyPI visibility handling with bounded retries while rejecting conflicting publication
  data. Fetch the exact final tag before manifest sealing and allow matching existing PyPI files
  to skip upload without skipping final publication.

Existing exact-source states and manifests remain supported. The materialization binding and
promotion evidence extend the v1 format; older tooling, including 0.1.3, cannot consume the new
materialized documents. Components adopting this path must upgrade their tooling pin and supply
trusted materialization policy, producer identity and independently retained handoff digests.
Build commands remain component-owned and must run without signing or publication credentials.
