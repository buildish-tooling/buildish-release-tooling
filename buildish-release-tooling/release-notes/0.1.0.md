This is the first public release of Buildish Release Tooling.

Highlights include:

- direct and candidate-to-promotion release lifecycles with exact-state validation;
- reproducible source and Python distribution preparation, checksums, and OpenPGP signing;
- GitHub Release and PyPI publication support, including Trusted Publisher attestations;
- machine-readable candidate, promotion, verification, and final-release manifests; and
- an offline release harness for exercising workflow composition without publishing externally.
